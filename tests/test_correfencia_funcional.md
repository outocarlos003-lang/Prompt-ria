# Casos normativos\n\nEstes casos documentam o comportamento esperado do validador:\n\n1. Menção genérica a um título existente -> correferência verdadeira e instrumento ativo.\n2. Descrição da função própria sem desvio -> instrumento ativo.\n3. Ordem normal para usar o instrumento em sua finalidade -> instrumento ativo.\n4. Atribuição de outra finalidade -> instrumento inativo para essa ocorrência.\n5. Atribuição de outro papel -> instrumento inativo para essa ocorrência.\n6. Dois ou mais títulos genéricos na mesma requisição -> todos permanecem ativos individualmente.\n7. Um título com função diversa não desativa títulos distintos que permaneçam genéricos.\n8. Silêncio quanto à função não constitui função diversa.
