# Prompt-ria
Promptária é um repositório de instrumentos promptuais que preserva inteligências operacionais. Cada título é uma chave; cada instrumento, uma possibilidade de ação. Recuperados pelo GitHub e acionados no ChatGPT, atravessam contextos sem perder a essência: preserva-se a lógica, adapta-se a forma, executa-se a ação.
