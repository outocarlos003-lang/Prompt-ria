Promptária

Repositório de instrumentos promptuais. Cada título é uma chave; cada instrumento, uma possibilidade de ação. Esta interface lê os instrumentos diretamente do GitHub, permite pesquisá-los, visualizar seu conteúdo e copiá-los para uso no ChatGPT.
